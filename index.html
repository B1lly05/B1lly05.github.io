Proyectos realizados

Gestión de una empresa en C

Desarrollé un sistema en C para gestionar la información de 20 empleados. El programa permite almacenar IDs, registrar horas de entrada y salida, calcular el salario mensual basado en horas trabajadas y automatizar el cálculo de finiquitos en caso de despido.

Sistema de Farmacia en Java

Trabajé en equipo para desarrollar el software de gestión de una farmacia. Implementamos un sistema donde cada fármaco dispensado actualizaba el inventario, calculando de manera dinámica la nueva posición de los productos restantes mediante algoritmos estructurados.

Laberinto en Python

Programé un videojuego de escape de un laberinto jugable tanto en terminal como en interfaz gráfica. El juego integra mecánicas de exploración, recolección de botín (loot) y un sistema de combate básico contra enemigos generados en el mapa.
